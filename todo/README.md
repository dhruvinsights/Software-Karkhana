Everything about what is planned, in progress and done lives here. If you work on the project, update this folder in the same commit as your code.

| Path | What it is |
|---|---|
| [`MASTER_TODO.md`](MASTER_TODO.md) | The big checklist, idea to live GCP deploy. Tick a box only after its check passes. |
| [`logs/`](logs/) | One log file per person. Add a short entry for every working session. |
| [`wikis/`](wikis/) | Short how-to notes: run it locally, accounts for rehearsal, GitHub board, conventions. |

## Rules

1. Before you start, read `MASTER_TODO.md` and pick an unticked item. Put your name next to it.
2. When it is done, run the check written on the item. Only then change `[ ]` to `[x]`.
3. Add one row to the progress log at the bottom of `MASTER_TODO.md` and one entry in your file under `logs/`.
4. Commit the code and the todo update together. No AI credit in commit messages.
